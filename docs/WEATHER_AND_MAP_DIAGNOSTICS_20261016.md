# 天氣請求與地圖診斷（2026-10-16）

## 天氣

- 同一組座標與預報參數的成功回應重用 15 分鐘，正在進行的相同請求共用一次下載。一般行程預報可跨重新整理與行程切換重用；目前位置要求的新 HTTP 快取僅存記憶體，不新增位置歷史儲存。既有單筆目前天氣快取維持原本行為。
- 預報逐地點取得，任何一筆失敗即停止後續地點；已成功取得者仍可供下次請求使用快取。整份預報失敗時保留既有顯示資料。
- `429` 在所有 Open-Meteo 預報要求間共用冷卻，重新整理也保留。支援 `Retry-After` 秒數與 HTTP 日期，至少等待一分鐘；服務若要求更久則依其要求。冷卻期間不自動重試。
- 天氣詳情顯示服務忙碌與可重試時間，暫停重新整理操作，期滿恢復。快取不偽裝成剛取得的資料，更新時間保留實際下載時間。
- 個別呼叫者取消不會中斷另一個呼叫者共用的下載；單次下載最多等待 15 秒，逾時呈現失敗狀態。

這些措施減少前端不必要的請求，無法保證供應商或共用網路 IP 不再被限流；首次收到的 429 仍可能出現在瀏覽器主控台。

## 地圖診斷

以 `https://fcwi.github.io/trip_agent/?trip=2027_tohoku&mapDebug=1` 開啟並照常解鎖，切到第一天、深色模式及互動地圖，縮小到原警告出現的範圍。主控台的 Info 訊息以 `[TripAgent map diagnostic]` 開頭，可用 `TripAgent` 篩選。缺圖示另外以 `[TripAgent map missing image]` 記錄。

分析器只在帶 `mapDebug=1` 的地圖載入，排除於 PWA 預先下載。一般地圖不啟用診斷。正式建置僅保留安全的 `console.info` 診斷，其他既有除錯輸出仍移除。

分析器使用與現有地圖相容的官方樣式表達式套件，依目前縮放、圖層可見性與一般篩選，抽樣已下載圖磚的地物並重新求值，列出重現數字空值錯誤的圖層、來源別名與屬性。報告只包含上述名稱、縮放、主題、取樣數與截斷標記，不含來源網址、金鑰、地物屬性值、座標或地物 ID；沒有上傳服務。

每個來源圖層最多抽樣 150 筆、總求值上限 10,000 次，每張地圖最多輸出 8 組不同結果。需要 worker 圖磚幾何脈絡的篩選會略過並計數。報告是候選定位資訊，不能取代 worker 的完整脈絡，也不能以空白結果宣稱所有圖磚無問題。

本次未取得使用者實際供應商圖磚的診斷結果，沒有猜測修改所有數字欄位、替換地圖服務或消除原始警告。需要再依重現後的報告做針對性修正。
