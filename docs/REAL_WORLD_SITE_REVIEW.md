# 旅行實際使用流程複查

範圍：從行前準備、行程切換、旅途中導航與天氣、翻譯／導遊、記帳記事、登入／登出，到離線重開與慢速網路。檢查原始碼與本機 Chromium，使用假服務與測試密碼；不操作真實收據、不寫入正式 GAS、不呼叫付費 AI。

## 本次發現並修正

| 優先性 | 使用情境與原問題 | 修正與驗證方向 |
| --- | --- | --- |
| 高 | 網路中斷時登出請求未到伺服器，重新整理可能恢復舊登入 | 本機待完成登出狀態阻擋自動登入；恢復網路後先完成撤銷。驗證失敗登出後重新整理仍鎖定 |
| 高 | 另一分頁登出，已開啟／返回快取的頁面仍顯示舊內容 | 跨分頁鎖定事件與 pageshow 驗證；不以 localStorage 密碼恢復登入 |
| 高 | 聊天儲存先刪舊資料，再另開交易寫新資料，失敗可能清空對話 | 同一 IndexedDB 交易覆寫，失敗回滾；以不能寫入的資料驗證舊紀錄保留 |
| 高 | 看完回覆立刻切模式，500ms 延遲儲存尚未執行，近期對話可能消失 | 切換前完成對話快照，圖片也完成本機保存；儲存失敗保留目前模式並提示 |
| 高 | 編輯／批次匯入先顯示成功，立即重開可能遺失修改 | 編輯先提交本機交易，批次採單一追加交易；失敗保留原資料與編輯內容 |
| 中 | 本機刪除失敗仍移除畫面紀錄 | 中止刪除流程，撤回此次待刪隊列並提示重試，不回報假成功 |
| 中 | 離線圖片記事顯示「已保存至雲端」 | 改為本機保存提示，雲端狀態由個別紀錄圖示顯示 |
| 中 | 手機沒有滑鼠 hover，記帳編輯／刪除與收據移除入口不明顯 | 觸控裝置直接顯示，鍵盤焦點顯示操作按鈕 |
| 中 | 未取得匯率時將花費換算為 TWD 0，造成誤導 | 顯示未換算，日合計標示含未換算紀錄；保留原幣金額與已保存換算 |
| 中 | 部分舊資料缺 user 欄位會造成紀錄畫面錯誤 | 缺少使用者欄位時不再直接解參照而崩潰，不推定該紀錄的編輯權限 |
| 中 | session 過期、GAS 設定錯誤均變成一般網路問題 | 401 提示鎖定後重新登入；GAS 僅保留白名單錯誤代碼、不回傳原始敏感錯誤文字 |
| 中 | 登入網路請求可能長時間無結果 | 45 秒逾時；區分密碼錯誤、登入頻率限制與主機啟動／連線問題 |
| 中 | 新後端登入架構與舊版前端解密測試不一致 | 更新瀏覽器／正式產物測試，使用真實後端登入處理器及假上游；CI 增加後端測試 |
| 中 | PWA 測試仍宣稱可以離線冷啟動並進入行程 | 改為驗證離線保持鎖定、連線登入後恢復本機資料，更新登入畫面與文件 |

## 流程覆蓋

- 三個旅程的行前／旅程中／回顧內容、行程選擇、獨立準備清單與記帳範圍。
- 日程展開、地圖標記與對話框、地圖引擎／路線／圖資失敗的替代連結與恢復。
- 天氣失敗、重試、限流冷卻與快取提示，計算機輸入狀態。
- 翻譯目的語言與純翻譯分流、導遊對話／搜尋、模式切換與回覆保存。
- 記帳新增、編輯、離線保存、同步錯誤、原幣與未換算狀態；記事圖片保存提示。
- 320px／390px 淺深色及桌面版面、鍵盤焦點、工具列與固定導覽列間距。
- 登出跨分頁與重新載入、頁面返回快取、HttpOnly session、密碼不落地。

## 尚存的產品與部署界線

1. **離線冷啟動需連線驗證**：保持密碼保護，沒有加入本機旗標繞過；已開啟畫面可使用本機資料。若希望飛航模式下重開也能解鎖，需要另行設計真正的離線驗證。
2. **靜態行程不是機密資料庫**：行程內容仍在公開建置檔內。密碼保護 API 與進入介面，若行程本身須保密，需移至受保護 API 或存取閘道。
3. **本機資料與舊網站遷移**：聊天、清單、未同步記帳／圖片屬於各瀏覽器與網域。換手機、清除瀏覽資料，或從 GitHub Pages 換到 Render，不會自動搬移；目前沒有完整備份／還原介面。
4. **雲端真實權限仍需正式驗收**：Google grounding 付費權限、MapTiler 網域限制、每個 GAS 旅程的試算表／圖片資料夾仍取決於實際帳戶設定。本次不寫入真實雲端資料。
5. **免費主機與共享登入**：Render 休眠／重啟會清除記憶體 session；使用者需重新登入。反向代理後的 IP 限流可能由多位旅客共用；單一 instance 設計尚未改為共享 session 儲存。
6. **舊部署與舊金鑰**：新站無法使舊站或已發出的 key 失效；舊 GitHub Pages 與曾在前端使用的私密金鑰仍須由帳戶管理者完成退場／輪替。

GitHub 的舊版本 CI 通知與 Render 部署狀態是兩件事。本次修復已過時的測試；未取得舊通知的完整遠端日誌，因此不認定那封信全部失敗原因都相同。正式遠端 CI 結果須在推送後由 GitHub Actions 確認。

## 本次驗證結果

- `npm run check`：110 項單元測試、ESLint、來源機密掃描通過。
- `npm run test:server`：登入／cookie、來源限制、session 到期、GAS 白名單錯誤、敏感訊息遮蔽及固定上游代理檢查通過。
- 完整本機瀏覽器回歸：55 項通過；可靠性子集另外覆核寫入失敗、匯率未取得與刪除失敗。
- 正式 PWA：東北 4 組、釜山與輕井澤 8 組，共 12 組離線／慢速網路情境通過。
- 正式建置與產物檢查通過。大型地圖／HEIC 選用資源仍會產生大小警告，維持按需載入；不視為建置失敗。

上列均為本機結果；未取得舊 GitHub Actions 的詳細日誌，也未宣稱正式 Render、Google、GAS 與 MapTiler 的整合驗收已完成。
