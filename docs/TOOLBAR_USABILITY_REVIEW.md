# 記帳與 AI 導遊工具列可用性複查

依專案 `.agent/workflows/ui-ux-pro-max.md` 的檢查表進行；引用的 `.shared/ui-ux-pro-max/scripts/search.py` 未安裝，未執行資料庫搜尋。

使用本機 Chromium、模擬登入及測試旅人資料，檢查 finance / ai 兩頁、320 / 390 / 768 / 1024 / 1440px、淺色 / 深色，共 20 組畫面。未呼叫正式 Gemini / GAS。

- 模式切換與搜尋、同步或清除維持單行，沒有水平溢出或按鈕被裁切。
- 頭像與所有工具列按鈕均至少 44 × 44px。
- 模式文字 14px；aria-pressed 提供選取狀態，搜尋提供 aria-expanded，圖示按鈕提供名稱。
- 搜尋開關、模式切換、帳號選單與鍵盤焦點可操作。
- 手機保留頭像與模式名稱；姓名可從帳號選單查看。全部展開／收折移入帳號選單，避免擠壓工具列。
- 以計算樣式合成背景後檢查工具列文字與圖示對比，文字至少 4.5:1，圖示至少 3:1；排除彩色頭像與停用控制項。依測試結果補強搜尋圖示對比。
- 工具列按鈕使用顏色過渡、不做尺寸縮放，支援 reduced-motion；保留清除對話確認流程。

限制：屬於本機 Chromium 的畫面、DOM 與互動檢查，未替代實體裝置、螢幕閱讀器或正式站驗收。
