# 多行程切換與分季節插畫

## 使用方式

登入後，頁首匯率旁提供「切換行程」按鈕，可在東北、東京輕井澤與釜山之間切換。選擇視窗列出旅程日期、狀態及不同封面插畫；目前行程有文字與勾選標示。切換沿用登入，無須先登出，也無須重複輸入密碼。

未指定旅程的網址會以目的地時區判斷：優先選旅程中的行程，其次選最近尚未出發的行程，若全部結束則選最近結束者。出發及結束當天都算旅程中。網址 `?trip=<id>` 則保留使用者明確選擇，重新整理與分享連結不會跳回預設旅程。

以 2026/10/15 為例，未指定時會選 2027/1/22 出發的東北行程；仍可切換至已結束的 2026 輕井澤與釜山。行程期間保留原先優先顯示當日安排的行為，亦可點「總覽」回顧完整旅程。

## 資料與相容性

- 行程不再由建置時固定為唯一資料來源；三份既有行程都包含在登入後載入的區塊，入口不預載完整行程。
- 登入狀態改為同一個網站共用；舊的旅程登入資料可遷移，鎖定會清除共用及舊登入值，不刪除行程內容。
- 切換透過帶 trip 參數的頁面導覽重新建立完整旅程脈絡，避免記帳、聊天、資料庫及尚未完成的請求沿用前一旅程。瀏覽器返回也使用網址對應的行程。
- localStorage、IndexedDB、聊天及記帳仍依選定的 tripId 分隔；釜山既有資料庫名稱保留。未分區的舊資料只交給原先部署行程遷移，不會複製到每一份旅程。
- GAS 請求使用實際選定的 tripId；既有自訂 GAS Property 僅套用原先部署的行程。其他行程沿用後端既有按 tripId 分配資源的機制，不讀取前端指定的 Spreadsheet ID。
- 手動選擇的明暗模式會保留。鎖定後，從瀏覽器頁面快取恢復的舊頁也會重新檢查登入。
- PWA 保留原本安裝識別，名稱改為通用的 Trip Agent 旅行手帳；離線快取包含三份行程與插畫。

正式環境設定未修改，亦未向真實雲端提交測試記帳、聊天或定位。切換前尚未送出的表單輸入仍屬當頁狀態；已儲存的記錄、清單及聊天不會因切換刪除。

## 插畫配置

圖稿放在 `src/components/Itinerary/artwork/`，由 `src/config/tripCatalog.js` 指定 `artwork.id` 與 `season`。

| 旅程 | 插畫 |
| --- | --- |
| 東北・森吉樹冰 | 雪山、雪樹、溫泉街屋、樹冰纜車與遊覽車 |
| 東京・輕井澤 | 雪林、山間小屋、列車、雪人與冬季山景 |
| 韓國・釜山 | 海灣、跨海橋梁、彩色街屋、海岸列車與帆船 |

封面、每日圖章及選擇視窗共享各旅程的插畫設定。冬季每日圖章也改用雪地及雪花，而非共用夏季綠地。圖稿沿用手繪墨線與粉彩，不加入額外圖片服務，明暗模式均使用相對應色票。

## 驗證

- 日期選擇與時區邊界、明確指定／無效網址、共用登入遷移及鎖定等單元測試。
- 三行程登入後互切、清單保留與隔離、記帳帳號分開、GAS 使用對應 tripId、鎖定及快取頁恢復測試。
- 行程選擇視窗的 320／402／412px 直向及 874px 橫向、明暗模式、Tab／Shift+Tab／Escape 與焦點還原；背景在視窗開啟時不可操作。
- Chrome／WebKit 的三套插畫、每日頁、選擇視窗與無橫向溢出檢查，預覽保存在忽略的 `test-run.local/seasonal-trips/`。
- 正式建置的離線、慢網路、字型快取與頁面恢復；離線往返三個行程並確認原行程的記帳保留，其他行程不出現該筆資料。
- 原有行程、地圖、小工具、通知、導覽及記帳回歸，以及 lint、來源安全與正式建置產物檢查。

測試使用隔離設定及受控外部回應，沒有宣稱真實服務的額度或各舊旅程的歷史內容已重新查核。實際手機仍建議套用更新後操作確認。修改前來源備份為忽略的 `backups.local/before-trip-switcher-a0bc545.zip`。
