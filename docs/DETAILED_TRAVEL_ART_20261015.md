# 插畫細緻化與每日場景

## 修改內容

依既有旅行手帳風格延伸原創 SVG：將封面粗筆線調細，加入屋簷、木板、窗格、鐵道、橋梁欄杆等細節。保留明暗模式共用色票，冬季旅程使用積雪與冬樹，釜山使用夏日海岸。

每日插畫從標題關鍵字判斷改成獨立日期對照，共 16 張不同構圖；不再將多個日子都指向同一張山景。總覽目錄與每日頁使用同一張對應圖稿。首頁相機／機票／行李箱裝飾改為各行程首日、中間日與末日的小風景卡；移除每日簡介旁反覆使用的通用貼紙。

| 行程 | 每日場景 |
| --- | --- |
| 東北五日 | 天童雪夜溫泉、銀山溫泉街、森吉樹冰與列車、猊鼻溪輕舟與草莓、松島海灣 |
| 輕井澤六日 | 淺間山與新幹線、雪橇與雪人、上野街市、六本木燈景、台場海灣、成田航廈 |
| 釜山五日 | 西面湯飯街景、青沙浦膠囊與燈塔、廣安里橋景與無人機、甘川山城、白淺灘步道 |

圖稿為簡化的氣氛插畫，不是精確地圖或建築外觀紀錄。沿用靜態 SVG，無外部圖片請求、濾鏡或動畫；裝飾圖稿不接收焦點，對螢幕閱讀器隱藏。沒有修改行程文字、日期、金鑰或儲存隔離方式。

## 維護位置

- `src/components/Itinerary/artwork/`：三個封面、三組每日圖稿、筆觸元件與色票。
- `dailySceneCatalog.js`：行程 ID／日期順序到場景 ID 的對照。更動行程順序或天數時須同步調整。
- `DailyArtwork.jsx`：圖稿選擇與首頁小卡。
- `DayItinerary.jsx`、`TripDayIndex.jsx`、`TripCover.jsx`：依目前行程與日期顯示圖稿。
- `src/styles/journal.css`：小風景卡排版，移除不用的貼紙樣式。
