# 深色海域標籤字級修正（2026-10-16）

使用者的實際診斷在深色、縮放 2.9 時指出：

- 圖層：`Sea labels`
- 來源別名：`maptiler_planet_v4`
- 來源圖層：`water_label`
- 屬性：`layout.text-size`
- 錯誤：需要數字卻得到 null

原報告為已載入圖磚抽樣，且有截斷標記，不能據此宣稱其他圖層均無問題。報告沒有包含原始字級表示式，因此不猜測實際缺少哪個地物欄位。

## 修正

只針對上述識別條件相符的深色海域標籤，改用隨縮放連續變化的 12–20px 字級。這個字級不讀取地物屬性，避免缺值進入數值運算；保留文字內容、其他排版、來源與其餘圖層。亮色樣式不套用這項調整。

使用官方 [`setStyle` 的 `transformStyle`](https://maplibre.org/maplibre-gl-js/docs/API/type-aliases/TransformStyleFunction/) 在下載樣式後、交給地圖套用前完成修正，避免等到 load 事件才調整而已經產生第一批圖磚警告。保留既有診斷，不攔截或隱藏引擎警告。
