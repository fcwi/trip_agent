# 插畫與卡片層次打磨

延續 16 張每日場景，調整封面景深與整體外框的主次。

- 三個封面共用淡彩漸層，各實例使用獨立 SVG ID，避免行程選擇視窗同時顯示多張封面時互相引用。
- 遠山、山丘與跨海橋使用較淡、較細的筆線；主體維持清楚輪廓，增加地面投影與各自的前景枝葉。
- 每日淡彩底改成兩層不規則色塊，木屋增加輕微不對稱屋頂、淡影與局部細線。
- 封面小卡減輕邊框、陰影及傾斜角度，略縮小尺寸，讓主景先被看見。
- 資訊面板、指南／商店內卡、行程卡、分類標籤與每日天氣改用細線；行程卡使用柔和陰影。
- 總覽每日標題移除重複粗底線；日期列、操作按鈕、焦點樣式與主要文字配色沿用原設定。

圖稿仍為靜態 SVG，沒有新增圖片下載、濾鏡或動畫。未修改行程資料與私人環境設定。
