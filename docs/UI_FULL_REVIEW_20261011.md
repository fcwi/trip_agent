檢視首頁、Day 1–5、指南、商店、AI 導遊與記錄頁，共 10 個頁面狀態。額外檢視完成暱稱設定後的記錄輸入表單，並核對編輯視窗與加密工具原始碼。

瀏覽器矩陣：WebKit 402×874、874×402、402×874／125% 文字；Chrome 412×915、480×1040、915×412、320×740。每種設定皆檢視明暗模式與 reduced-motion 偏好，共 14 組、140 個頁面狀態檢查。

瀏覽器測試使用假憑證與隔離資料，封鎖外部服務請求；地圖／天氣的未設定或離線畫面屬測試條件，不代表正式網站故障。這是瀏覽器模擬，並非實體 iPhone／Galaxy 或原生 Dynamic Type 認證，也不是完整 WCAG 合規認證。

## 本輪改善實作

上述六項已實作：

- 記錄輸入欄位補上持續可見的金額（含幣別）、項目說明／記事內容標籤，編輯欄位補上 label 關聯。479px 以下採兩列控制區，輸入框保持完整寬度。
- 每日彩色標題、首頁天氣卡片與航班票券標題改用可讀的前景色；實際明暗模式前三日的次要文字對比測試皆達 4.5:1。
- 記錄與導遊的搜尋／同步／清除／朗讀、輸入工具、模式切換與天氣操作加大至至少 44px；獨立記錄表單檢查未再發現小於 44px 的可見按鈕。
- 全站 Framer Motion 接入使用者減少動畫偏好；日期頁在該偏好下停用滑動與淡入淡出，測試確認切換沒有水平位移。
- 加密工具改為管理者入口，明確區分 Gemini、Google Maps、MapTiler、雲端服務網址與 Token，並提示相應設定欄位；加密演算法維持原樣。
- 產生重新命名的 OFL 字型子集 `TripJournal-Regular.woff2`，保留來源中 1,815 個支援字元。檔案由 2,123,724 降為 344,028 bytes（約減少 84%），PWA 預快取總量由約 3,132.6 降為 1,397.2 KiB。其他使用者輸入字元使用系統字型 fallback；新增 UI／旅程文字後應執行 `scripts/subset-journal-font.py` 重新生成。

改善前來源備份為忽略的 `backups.local/before-ui-remediation-7c34e47.zip`。改善後版面與表單證據儲存在忽略的 `test-run.local/ui-remediation/`；完整正式建置 runtime 測試使用獨立 `test-run.local/production-audit/`，不接觸正式服務或記錄。
