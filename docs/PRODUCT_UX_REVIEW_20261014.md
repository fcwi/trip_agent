# Trip Agent 商品化 UI／UX 檢視（2026-10-14）

## 方法與設計方向

使用本機 UI/UX Pro Max skill，參考庫版本 `67803ea`。已讀取 SKILL.md、quick-reference.md 的可用性／操作／效能重點與 pro-rules.md；依既有 React 與 Tailwind 架構搜尋 `focus not obscured`、`error recovery mobile`（UX）及 `accessible async forms`（React）。採用與本網站符合的焦點可見、錯誤恢復、可辨識表單與非同步錯誤處理建議，不套用無關的泛用設計產出。

維持已確認的原創手繪插畫、紙張背景、粉彩與墨線風格。網站是供旅途中使用的行程工具，優先改善閱讀、操作與狀態一致性；不為追求裝飾增加大型圖片或動畫。

## 檢視範圍

登入與管理者設定、首頁、每日行程 1–5、指南、商店、AI 導遊、記錄／記事、地圖彈窗、天氣狀態及更新通知。另核對錯誤密碼、首次定位失敗、無天氣資料、更新失敗、鍵盤焦點、系統配色與手動配色衝突等情境。

## 商品視覺基線

- 同一層級使用一致的紙張表面、圓角、墨線與 Lucide 控制圖示；景點章與遊覽車保留原創 SVG。
- 主要正文、欄位與錯誤訊息保持可讀；小型資訊標籤不承擔主要閱讀內容。
- 單頁主要操作清楚，次要資訊逐步展開；五項主導覽及日期按鈕維持明確操作。
- 明暗模式使用配對色彩；待處理、停用、錯誤與成功狀態有文字／語意，不僅靠顏色。
- 更新提示可稍後處理，破壞性操作保留確認；非同步錯誤有恢復方向；既有記錄與行程狀態不因視覺改動重設。
- 手繪裝飾用於識別與分隔，正文保持素底，支援減少動畫偏好。

## 驗證與實務限制

瀏覽器配置：WebKit 402×874、874×402、402×874／125% 文字；Chrome 412×915、480×1040、915×412、320×740，兩種主題共 14 組。每組核對 10 個頁面狀態，共 140 項。這是瀏覽器模擬，不宣稱為實體手機或原生 Dynamic Type 認證。

登入頁主題切換完成後的提交按鈕對比：亮色 7.54:1、深色 9.16:1；另檢查欄位錯誤與橫向溢出。44 CSS px 作為本站手機操作目標，不混同原生 pt／dp 或完整 WCAG 認證。

原先 MapTiler 的數值空值與缺少圖示警告仍需實際 style.json 圖層內容定位。本次地圖測試使用隔離樣式驗證操作與失敗恢復，未宣稱正式外部服務的全部圖層警告已消失。

最終驗證：69 項單元測試、37 項端到端測試、14 組配置／140 個頁面狀態、4 組正式建置離線／慢網路情境皆通過。lint、來源安全與正式建置產物檢查通過。登入頁主題完成切換後逐張核對；正式 API 設定與本輪備份保持一致。
