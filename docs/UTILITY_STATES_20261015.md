# 小工具一致性與服務狀態

## 介面

- 天氣、計算機與互動地圖統一細邊框、陰影、18px 標題及 44px 關閉按鈕。
- 天氣及計算機的標題列保持在捲動容器頂部，橫向或較矮畫面仍能關閉。
- `UtilityState` 統一載入、離線、無資料、錯誤與重試提示，使用清楚的正文、狀態宣告與可辨認的操作。共用於小工具、地圖及功能載入畫面；旋轉圖示遵守減少動態效果設定。

## 行為修正

- 每日天氣沒有預報時仍可開啟詳情，顯示原因並在原視窗重試。
- 天氣更新失敗或離線時，保留已取得的數值及更新時間；空資料不顯示完整數據面板，不再以「多雲」或降雨 0% 充當預設值。
- 未提供的逐時／每日預報顯示說明，缺少或無效的溫度不建立預報列；最高與最低溫相同時避免圖表除以零。
- 計算機只在開啟或切換貨幣設定時重設。匯率更新、失敗或恢復都保留輸入及未完成算式，僅停用無可用匯率的換算鍵，一般計算繼續可用。
- 修正非有限運算結果顯示與長數字輸入上限，長數字縮小顯示以降低溢出風險。

## 驗證

- 程式檢查、來源機密掃描、77 項單元測試通過。
- 既有測試及新增狀態測試 45 項通過；另 1 項整合測試確認實際每日頁預報失敗後，可開啟詳情並於原視窗重試成功，共 46 項。
- 原有小工具版型檢查涵蓋 320×740、402×874、412×915、874×402 的明暗模式；額外以 WebKit 402×874／874×402、Chrome 320×740 檢查載入及離線狀態、容器邊界、水平溢出及捲動後的關閉按鈕。
- 已人工查看一般及離線預覽。正式建置與輸出驗證通過。
- 外部服務錯誤採隔離測試，不以真實金鑰發送測試要求；瀏覽器模擬不等同實機認證。
