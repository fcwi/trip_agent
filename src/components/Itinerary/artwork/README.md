# 旅程插畫

每個旅程使用獨立、原創的 SVG 元件，與頁首、行程資料及業務操作分開：

- `TohokuSnow.jsx`：東北雪國、樹冰纜車、積雪溫泉小屋與遊覽車。
- `KaruizawaSnow.jsx`：輕井澤雪山、針葉林、山間小屋、列車與雪人。
- `BusanCoast.jsx`：釜山海灣、跨海橋梁、彩色街屋、海岸列車與帆船。
- `ScenePrimitives.jsx`：共享的畫框、雪樹、雪花與遊覽車筆觸。
- `TripArtwork.jsx`：以旅程目錄中的 `artwork.id` 選擇圖稿。

在 `src/config/tripCatalog.js` 設定旅程的 `artwork.id` 與 `season`。封面、每日圖章、行程目錄及選擇視窗會使用同一份設定，不從城市名稱推斷季節。冬季景色採積雪色票；釜山夏季採海岸色票。明暗配色使用共用 CSS 變數，不依賴 SVG 外部圖片或下載服務。

新增行程圖稿時，請建立獨立元件，再於 `TripArtwork.jsx` 的對應表登錄。保持裝飾 SVG 的 `aria-hidden` 與可縮放 viewBox，不加入焦點、點擊行為或可辨識的私人資料。

## 每日風景小品

每日頁與總覽目錄共用 `DailyArtwork.jsx`，以 `dailySceneCatalog.js` 的行程 ID 與零起算日期順序指定圖稿，與標題文字脫鉤。調整行程天數或順序時，應同步調整這份對照表；未登錄的日子不顯示錯誤景色。首頁的三張小卡擷取首日、中間日、末日，代表該旅程的不同面貌。

- `TohokuDays.jsx`：天童雪夜溫泉、銀山街屋與拱橋、森吉樹冰與秋田列車、猊鼻溪輕舟與草莓、松島島嶼與遊船。
- `KaruizawaDays.jsx`：淺間山與新幹線、雪橇與雪人、上野街市、六本木燈景、台場海灣、成田航廈。
- `BusanDays.jsx`：西面湯飯街景、青沙浦膠囊與燈塔、廣安里橋景與無人機、甘川山城、白淺灘步道。
- `DailyScenePrimitives.jsx` 與 `artPalette.js`：細筆窗格、木屋、樹木、列車、水紋與共用明暗色票。

16 張圖稿各自安排前景、主體與遠景；共享筆觸與色票，不以同一張圖搭配不同裝飾充當每日插畫。以簡化風景表達當日氣氛，並非精確地圖、建築測繪或景點外觀保證。保持圖稿靜態、無外部圖片請求、無 SVG 濾鏡，確保手機與離線使用。
