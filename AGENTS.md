# Trip Agent visual baseline

The user finalized the visual direction on 2026-10-23. See
`docs/ui-ux-baseline-2026-10-23.md` for the review and validation record.

- By default, subsequent work should improve itinerary content, destination guidance,
  and real shop information. Preserve the established layout, typography, palette,
  illustrated travel notebook identity, vehicle navigation, stickers, and glass navigation.
- Keep one shared header style across all tabs. Preserve the usable viewport and
  keyboard behavior of both AI and records, including independently scrolling content.
- Display temperature ranges consistently: high temperature on the left, low on the right.
- Content-related wrapping and overflow fixes are appropriate without redesigning the UI.
- Distinguish confirmed information, optional activities, and unconfirmed suppliers.
  Use actual branch names and authoritative sources; label map searches as searches.
- New explicit user requests take precedence over this baseline. Do not deploy unless
  deployment is requested or already authorized for the current changes.
